Executive Summary

Dt3rmind

Ask for the tool, not the answer.

A gamified, chess.com-puzzle-style web course that teaches non-technical adults how to direct AI reliably — built as a HackMidwest project with a three-minute judging pitch.

Verified against the codebase · 2026-10-21 — figures read from live source, authored packet JSON, npm test, and npm run build.

What it is

Stop asking for the answer. Ask for the tool and the check.

Determinism comes from the tools you force the AI through, not the words you give it.

Rather than teaching cleverer prompting, Dt3rmind teaches people to stop asking AI for the answer and instead ask for the tool and the check that make an answer exact — and to prove it.

Primary audience: non-technical adults who already use chat AI. A technical skin of the same levels targets developers.

The problem it dramatizes

Same model, same data — one approach is exact.

Ask an AI to total 2,000 rows of sales data and you get five different wrong numbers (179K–442K): the model predicts what a total looks like rather than computing it. Ask it to write a formula and let a spreadsheet run it, and you get the exact answer every time.

Product shape

7 worlds · 31 authored level packets

  • 7 worlds, each with 3 practice levels plus a boss. World 2 carries an extra level; World 4 adds a keystone (w4-l4); the capstone is a second, higher-order boss in World 7. Total: 31 packets.
  • 9 concrete "moves" (M1–M9) — sentences a learner adds to a real prompt (e.g. "ask for the tool, not the answer"). Popular prompting "tricks" are decoys that visibly fail.
  • The "false green" keystone: a checker reports 8/8 pass but is secretly broken — it matched "next" in "arrives next week" — teaching that an unproven check is a promise, not proof.
  • A technical skin carries plain and tech text for every chip.

Technical architecture

Pure, deterministic, fully client-side

FrontendVite + React 18 + TypeScript (strict) + Vitest. Client-side static SPA, HashRouter, progress in localStorage. No backend wired into the SPA.
Content31 JSON level packets drive a pure, deterministic engine (rules, stars, XP, independent pass oracle). Map/layout computed from packets.
EnginePure engine + 3 simulators (w4-l4-check, w4-check, w4-boss-refund). Independent oracle catches engine bugs.
Python harnessFastAPI + SSE, OpenAI/Bedrock/mock providers, seeded dataset (seed 42). Powers the real determinism beat; natural Phase-2 engine. Not imported by the app today.

SecurityAuthor HTML sanitized via dependency-free allowlist. react-router-dom 6.30.6; no high/critical advisories in the shipped bundle.
