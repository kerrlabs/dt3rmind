Try it in your AI
Any time the AI produces many things that must follow rules (emails, summaries, rows, tickets), copy this pattern:

      

      
    
        
  • ChatGPT with file or code tools: it can write and run the checker itself, so "run it" really happens.
    • 
        
  • Copilot in Excel: put the drafts in a column and ask for checker formulas, e.g. =ISNUMBER(SEARCH(B2, A2)) for "uses the name".
    • 
        
  • A chat AI that can't run code: it can't truly check its own work. Ask for the checker, then run it yourself in a spreadsheet. Never accept "I checked, they all pass."
