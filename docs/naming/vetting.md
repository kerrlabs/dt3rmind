# Name Vetting — "Puzzle Ladder" product

Product: gamified, chess.com-puzzle-style course teaching non-technical adults to stop asking AI for answers and start asking it for the *tools and checks* that make the right-answer steps exact. Thesis: "Determinism comes from the tools you force the AI through, not the words you give it."

Vetting method: web_search for product/company collisions; fetch of `<name>.com`/`.ai`; GitHub/npm checks where meaningful. Domain availability is a SIGNAL only — I cannot register or truly confirm. "Appears taken" = a live site answered; "unknown" = not checked or inconclusive.

## Shortlist — best 5, with taglines

Ranked for distinctiveness + on-thesis + apparent availability. All need a live domain + USPTO/handle check before commitment — treat as directional.

1. **Tool Moves** — *"Stop guessing. Learn the moves that make AI exact."*
   Fuses the chess/puzzle gameplay ("moves," ranks, bosses) with the thesis ("tools, not words"). GitHub org appears open; no product collision found. Strongest original.

2. **The Right Moves** — *"Don't let AI guess the part that has a right answer."*
   Leans fully into the chess-puzzle metaphor; warm, memorable, learner-friendly. Generic as a bare phrase, so pair with a wordmark/domain qualifier (e.g. rightmoves.ai) — needs availability check.

3. **Make It Prove It** — *"Your AI said 'done.' Make it prove it."*
   Best *tagline* in the set and it nails the demo. Already circulating as a phrase for this exact idea (Viaknox), so use it as the campaign line even if the product name is something else. Weaker as the standalone brand.

4. **Ask for the Tool** — *"Ask AI for the tool, not the answer."*
   Clearest one-line statement of the method; great for the pitch and level titles. Too long/imperative to be the product name — reserve as the hero line.

5. **Seen It Fail** — *"You've seen it guess. Now watch it fail — then fix it."*
   Captures the "just ask" fails-visibly loop that is the heart of each level. No collisions found. Downbeat and grammatically awkward as a brand; keep as a backup / world name.

**Recommendation:** lead with **Tool Moves** (or **The Right Moves**) as the product name and **"Make It Prove It"** / **"Ask for the tool, not the answer"** as the taglines. Avoid Checkmate AI, Don't Guess, Determa, PromptSmith, Prompt Dojo entirely — all collide, several with near-identical competitors.
